```ts
export async function refreshToken(userId: string, oldToken: string): Promise<string> {
  const row = await db.one("SELECT token FROM refresh_tokens WHERE user_id = $1 AND token = $2 AND revoked = false", [userId, oldToken]);
  if (!row) throw new Error("invalid refresh token");
  const next = crypto.randomUUID();
  await db.none("INSERT INTO refresh_tokens (user_id, token, expires_at) VALUES (...)", [userId, next, TOKEN_TTL]);
  await db.none("UPDATE refresh_tokens SET revoked = true WHERE token = $1", [oldToken]);
  return next;
}
```

- Thao tác SELECT → INSERT → UPDATE **không nguyên tử**, không có transaction/lock ⇒ khi 2 request chạy song song, cả hai đều đọc được token cũ còn `revoked = false` và cùng INSERT ra token mới ⇒ 2 token active cho `u_42` (fail #1 và #3).
- Token cũ chỉ được revoke *sau* khi đã cấp token mới, và việc kiểm tra lại "đã dùng rồi" phụ thuộc cột `revoked` được set ⇒ request song song thứ hai vẫn pass ⇒ token cũ được tái sử dụng trả 200 thay vì 401 (fail #2).
